## Features

- **Random Restaurant Picker**: With the click of a button you are able to get a surprise restaurant suggestion.  
- **Nearby Search**: Displays restaurants within a configurable radius using Google Places API.  
- **Filter by Category**: Limit results to Fast Food, Coffee, Casual Dining, etc.  
- **Firebase Authentication**: Optional sign-in with Google or email/password to save your favorites.  
- **Map View**: See your selected restaurants pinned on an interactive map.
